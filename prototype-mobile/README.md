# Phone prototype

The redesigned story framed for a portrait phone (1080 x 2340, 9:19.5): plain
HTML/CSS/JS, no build step. It is a reference for the phone port, like
`prototype-v3/` is for desktop; the site does not use it.

```
python prototype-mobile/serve.py        # http://localhost:4322, and your PC's Wi-Fi address
```

Open the Wi-Fi address on a phone on the same network. The server maps `/site/` to the
app's `public/` folder, so the real song, intro film, fly-through and journey photos
load from there without being copied. Any password works.

- Swipe up = further in, swipe down = back. A card that can still scroll keeps the swipe.
- `?scene=2` … `?scene=5` jumps straight to a screen.
- On a PC the phone is shown as a column in the middle; the wheel and arrow keys work too.

## How it was made

- `assets/` (except `content.js`) is generated by `scripts/design/prepare_portrait.py` from
  the desktop layers in `public/img/scenes/`. The screen 03 frame is the desktop grass ring
  rebuilt as a tall frame (corners kept, side bands mirror-tiled); 01 is a centred crop of
  the hill with the sky extended upward; 04/05 use the same crop the fly-through gets on a
  portrait screen.
- `assets/content.js` is the site's copy (`content/`, `config/site.ts`), dumped by
  `npx tsx scripts/design/dump-content.ts`.
