# Phone prototype

The redesigned story framed for a portrait phone (1080 x 2340, 9:19.5): plain
HTML/CSS/JS, no build step. It is a reference for the phone port, like
`prototype-v3/` is for desktop; the site does not use it.

```
python prototype-mobile/serve.py        # http://localhost:4322, and your PC's Wi-Fi address
```

Open the Wi-Fi address on a phone on the same network. The server maps `/site/` to the
app's `public/` folder, so the real song, intro film and journey photos load from there
without being copied. Any password works.

- Swipe up = further in, swipe down = back. A card that can still scroll keeps the swipe.
- `?scene=2` ... `?scene=5` jumps straight to a screen.
- On a PC the phone is shown as a column in the middle; the wheel and arrow keys work too.

## What each screen does (the 26 Oct review)

- **01 password**: the monitor on the hill sits vertically centred, with the heading, hint
  and Enter button under it.
- **02 login**: no monitor. The terminal fills the screen and its text block is centred.
- **03 intro**: the film fills the whole screen (no grass, no flowers, no bubbles). The song
  starts here, not on the password screen.
- **04 journey, 05 wedding**: the meadow and the river are drawn as depth layers, and the
  camera moves through them (03 to 04 behind a burst of static, 04 to 05 straight through
  the meadow into the valley). Plants sway and the river's ripples drift.
- **Header** (logo, Intro / Journey / Wedding, RSVP) is fixed at the top from the intro on and
  never moves. The **music button** is fixed bottom-left, one instance, with a speaker (off)
  or moving bars (on).
- The journey card and the wedding sheet are CSS glass (blur, tint, bright rim), no images.
- The terminal clicks as it types (Web Audio, no file). 03 to 04 dissolves (no static on the phone).
- The folder names ("our story", "and now, our new chapter begins") are text over the folder icons.

## How it was made

- `assets/` (except `content.js` and `world.js`) is generated by
  `scripts/design/prepare_portrait.py` from the desktop layers. Screen 01 is a centred crop
  of the hill with the sky extended upward.
- `assets/world/` and `assets/world.js` (the layer list the page reads) are generated by
  `scripts/design/build_world.py`: the same depth-layer cut as the desktop site's
  `public/img/world/`, re-cropped to the portrait frame. Run it again after changing the
  paintings or the depth rules; it writes both the desktop and the phone sets.
- `assets/content.js` is the site's copy (`content/`, `config/site.ts`), dumped by
  `npx tsx scripts/design/dump-content.ts`.
